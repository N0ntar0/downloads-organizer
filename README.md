# downloads-organizer

Windows のダウンロードフォルダを、ルールに従って種類別・話題別のフォルダに振り分ける PowerShell スクリプトです。

- **削除はしません。** 捨ててよさそうなファイルは `削除候補` に移すだけです。
- **迷ったものは勝手に決めません。** 判定に自信がないファイルは `要確認` に移し、行き先は CSV で人が指示します。
- **新しいフォルダを提案します。** よく出てくるファイル名の言葉から「このフォルダを作りませんか？」と提案し、採用するとルールに追加されます（AI は使いません）。

```
ダウンロード\
├ 00_整理\
│  ├ 要確認\      ← 自動で判定しきれなかったもの
│  └ 削除候補\    ← 捨ててよさそうなもの（削除はしない）
├ 書類\  画像\  動画・音声\  アーカイブ（zip）\  フォント\  その他\
└ （rules.json で決めた話題別フォルダ。例：授業\）
```

## 動作環境

- Windows 10 / 11
- Windows PowerShell 5.1（Windows に標準で入っています。追加のインストールは不要です）

## 導入手順

### 1. ファイルを置く

好きな場所に置いてください。以下では `ドキュメント\scripts\downloads-organizer` に置く例で説明します。

**Git を使う場合**

```powershell
cd $HOME\Documents
mkdir scripts -Force
cd scripts
git clone https://github.com/N0ntar0/downloads-organizer.git
```

**ZIP でダウンロードする場合**

GitHub の「Code」→「Download ZIP」でダウンロードし、展開したフォルダを置きます。インターネットから取得したファイルには実行をブロックする印が付くので、PowerShell で次を実行して外してください。

```powershell
Get-ChildItem "$HOME\Documents\scripts\downloads-organizer" -Recurse | Unblock-File
```

### 2. スクリプトを実行できるか確認する

PowerShell を開いて、次を実行します。

```powershell
Get-ExecutionPolicy -Scope CurrentUser
```

`RemoteSigned` か `Unrestricted` と表示されれば、そのまま次に進めます。`Restricted` や `Undefined` と表示された場合は、次を実行して自分のアカウントだけ許可します。

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### 3. ショートカットを作る

```powershell
& "$HOME\Documents\scripts\downloads-organizer\install.ps1"
```

デスクトップに **「ダウンロード整理」** のショートカットができ、同時に自分用のルールファイル `rules.json` が作られます（中身は `rules.example.json` のコピーです）。

### 4. まずはお試し実行する

実際には何も動かさずに、どこへ移すつもりかだけを表示します。初回は必ずこれで結果を確認してください。

```powershell
& "$HOME\Documents\scripts\downloads-organizer\organize.ps1" -DryRun
```

振り分け先がおかしいものがあれば、[ルールを変える](#ルールを変える) を参考に `rules.json` を直してから、もう一度お試し実行します。

### 5. 実行する

デスクトップの「ダウンロード整理」をダブルクリックします。終わると結果がダイアログで表示され、要確認や削除候補に新しく何か入ったときはそのフォルダが開きます。

## 日々の使い方

1. ダウンロードがたまったら「ダウンロード整理」をダブルクリックします。
2. `要確認` が開いたら、`_一覧.csv` を Excel で開いて **「振り分け先」** 列を埋めます。
3. `00_整理\要確認\_新フォルダ提案.csv` があれば、作りたいフォルダの **「採用」** 列に ○ を付けます。
4. 次に実行したとき、2 と 3 の指示どおりに移動されます。
5. `削除候補` の中身は、確認してから自分で削除してください。30 日以上置いてあるものがあると、実行のたびにお知らせします。

### `00_整理\要確認\_一覧.csv`

| 列 | 内容 |
|---|---|
| ファイル名 | 要確認フォルダ内のファイル名 |
| 理由 | 要確認に来た理由（例：弱いキーワード「企画」だけで判定） |
| 候補の行き先 | 当たっていそうなフォルダ（ある場合） |
| 移動日 | 要確認に移した日 |
| **振り分け先** | **ここに書く。** `書類`、`その他`、`書類\授業` のようにフォルダ名を書くと、次の実行でそこへ移す。`削除候補` と書くと削除候補へ移す |

`rules.json` にないフォルダ名を書くと、そのフォルダが作られ、以後は整理の対象外（自分で管理するフォルダ）として扱われます。

### `00_整理\要確認\_新フォルダ提案.csv`

要確認と、拡張子だけで振り分けた `書類` `画像` などのファイル名から、同じ言葉を含むファイルが `suggestMinFiles` 件以上あるものを提案します。

| 列 | 内容 |
|---|---|
| 提案フォルダ | 作るフォルダの名前。書き換えてよい |
| キーワード | 判定に使う言葉。カンマ区切りで複数書ける。書き換えてよい |
| 件数・例 | 当てはまるファイルの数と例 |
| **採用** | **○ などを書くと採用。** 次の実行でフォルダを作り、キーワードを `rules.json` に追加し、`書類` などに入っている該当ファイルも移す |

提案に出てほしくない言葉は、`rules.json` の `stopwords` に追加してください。

CSV は Excel で上書き保存してかまいません（文字コードが Shift-JIS になっても読めます）。ただし、**Excel で開いたまま実行すると CSV を更新できません。** 閉じてから実行してください。

## 判定のしくみ

ダウンロードフォルダ直下のファイルとフォルダを、上から順に調べて、最初に当てはまった場所へ移します。

| 順 | 条件 | 行き先 |
|---|---|---|
| 1 | ダウンロード中のファイル、`minAgeHours` 時間以内のファイル | 移動しない（次回に回す） |
| 2 | インストーラー、同名フォルダがある zip（展開済み）、中身が同じ `(1)` 付きのコピー、空のフォルダ | `削除候補` |
| 3 | 機密情報らしい名前（`.env`、auth・secret・token などを含む） | `要確認` |
| 4 | フォントのファイル・フォルダ | `フォント` |
| 5 | 話題別フォルダの **強いキーワード** を含む | その話題のフォルダ（複数に当たれば `要確認`） |
| 6 | **弱いキーワード** だけを含む | `要確認`（候補の行き先付き） |
| 7 | 拡張子で種類がわかる | `書類` / `画像` / `動画・音声` / `アーカイブ（zip）` |
| 8 | どれにも当てはまらない | `要確認` |

そのほかの動き：

- 移動先に同じ名前のファイルがあり、中身も同じときは `削除候補` へ移します。中身が違うときは `名前 (2).pdf` のように番号を付けて移します。
- `要確認` に残っているファイルも毎回判定し直すので、`rules.json` にキーワードを足せば次の実行で移ります。
- 移動の記録は `logs\移動ログ.csv` に残ります。

## ルールを変える

ルールは `rules.json` に書きます。メモ帳や VS Code で編集できます（文字コードは UTF-8 で保存してください）。

| 項目 | 内容 |
|---|---|
| `minAgeHours` | これより新しいファイルは移動しない（時間） |
| `staleDays` | 削除候補に何日置いたらお知らせするか |
| `suggestMinFiles` | 新フォルダを提案する最低件数 |
| `reviewFolder` / `trashFolder` | 要確認 / 削除候補の場所（ダウンロードからの相対パス。初期値は `00_整理\要確認` と `00_整理\削除候補`。JSON では `\` を `\\` と書く） |
| `skipNames` | 触らないファイル名 |
| `inProgressExtensions` | ダウンロード中とみなす拡張子 |
| `deleteCandidateExtensions` | 削除候補にする拡張子（インストーラーなど） |
| `sensitiveExactNames` / `sensitiveKeywords` | 機密情報とみなすファイル名 / 名前に含まれる言葉 |
| `fontFolder` / `fontNames` / `fontExtensions` | フォントの行き先 / フォント名（名前の先頭で判定） / 拡張子 |
| `otherFolders` | 整理の対象外にする、自分で管理するフォルダ |
| `keywordCategories` | 話題別フォルダ。`folder`（フォルダ名）、`strong`（これだけで決める言葉）、`weak`（要確認に回す言葉） |
| `extensionCategories` | 拡張子で決める種類別フォルダ |
| `stopwords` | 新フォルダの提案に使わない言葉 |

キーワードは大文字・小文字を区別せず、ファイル名に含まれていれば当たりとみなします。

話題別フォルダの例：

```json
"keywordCategories": [
  { "folder": "授業", "strong": ["時間割", "履修", "シラバス"], "weak": ["講義", "テスト"] },
  { "folder": "就活", "strong": ["エントリーシート", "内定", "インターン"], "weak": ["説明会"] }
]
```

`rules.json` は `.gitignore` に入っているので、`git pull` で更新しても自分のルールは上書きされません。新しい設定項目が増えたときは `rules.example.json` と見比べてください。

## コマンドラインのオプション

```powershell
.\organize.ps1                    # 実行する
.\organize.ps1 -DryRun            # お試し実行（何も動かさない）
.\organize.ps1 -Root D:\Downloads # 別のフォルダを整理する
.\organize.ps1 -Interactive       # 結果をダイアログで表示する（ショートカットはこれ）
```

## アンインストール

```powershell
& "$HOME\Documents\scripts\downloads-organizer\install.ps1" -Uninstall
```

ショートカットが消えます。そのあと、スクリプトのフォルダを削除してください。振り分けたファイルやフォルダはそのまま残ります。

## よくある質問

**「このシステムではスクリプトの実行が無効になっている」と表示される**
[導入手順の 2](#2-スクリプトを実行できるか確認する) を確認してください。ZIP でダウンロードした場合は `Unblock-File` も必要です。

**ファイルがどこへ行ったかわからなくなった**
`logs\移動ログ.csv` に、移動した日時・元の場所・移動先・理由が残っています。

**スクリプトを編集したら文字化けのエラーが出る**
Windows PowerShell 5.1 は BOM なしの UTF-8 を正しく読めません。`.ps1` は「UTF-8（BOM 付き）」で保存してください。
